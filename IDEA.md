Sail is an AI lab pioneering agentic finance. 

Sailor today is an open source harness for building and running onchain money agents. It lets users turn their coding agents into buildors and operators of money agents. Sailor tomorrow is the money agent; we're building a desktop app, an LLM orchestrator, tools for subagents, persistent memory, onchain data, and capital delegation powered by Sail Protocol. 

Sail Protocol is an open source, onchain primitive for Separately Managed Accounts (SMAs) run by agents.
