# create-sailor-agent

Scaffold a new Sail Protocol agent with one command:

```sh
npx create-sailor-agent my-fund
cd my-fund
# Open in Claude Code, Cursor, or Codex and say "start"
```

Thin wrapper around `sailor init`. The template includes a full DCA-rebalancer strategy,
the Sailor setup guide (`sail/WIZARD.md`), and a GitHub Actions cron job.
